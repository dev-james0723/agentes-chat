## Purpose and native seam

The existing reader prepares load_skill body plus bounded skillFileList, a selected stored-text path, or a folder listing. The gateway then applies pgSafeText and its separate50,000-unit cap. The preceding11 native disposable compatibility controls establish that pre-gateway text is not necessarily the displayed result. This module seals **already finalized text**, not a reformatted/re-read copy. It never calls the private skillFileList, duplicates the gateway cap or invents normalized paths.

`sealSkillReadSurface` accepts an observation of a successful native-shaped result, exact selected org/skill/version/operation/path/MIME, raw selected-source bytes where applicable, actual native listing/pre-gateway/suffix sidecars and explicit transformation flags. A future server-owned capture must provide these from the existing reader/finalizer. Input strings, flags, TypeScript types, callback booleans, brands or model-provided JSON do not establish native origin or permissions.

The helper has no IO or callback. It reuses sha256/canonicalJson, pgSafeText, native classifyFile and existing size constants. It rejects errors, non-text/image output, script/binary paths, unsafe/dot-alias paths, unknown operations or flag shapes, absent source bytes, inconsistent completeness/sanitization and unqualified truncation captures. It checks coherence of a gateway-truncated captured prefix plus explicitly supplied suffix; it does not reproduce the cap algorithm or attest that the actual gateway applied it. Reader-truncated/omitted flags are capture observations, not verified transformation provenance. Empty-folder explanations are accepted as captured text; the helper does not create/localize them. This is a bounded, deliberately narrow capture contract rather than coverage of every legacy read form.

## Digest and immutability contract

The returned UTF-8 buffer is encoded once and held privately. `readReturnedBytes()` returns a copy; the result, descriptor, selected identity and flags are frozen. Mutating input, raw bytes or a returned copy cannot change the sealed descriptor or later returned bytes. Raw bytes are copied once before hashing. No skill body, listing text, pre-gateway text, raw source bytes or exception string is serialized into the descriptor. Descriptor metadata/path still has the source's sensitivity; future receipt storage must retain the native audience and must not send it to JEV or global analytics merely because it contains hashes.

- `returnedBytesHash` hashes the exact supplied finalized UTF-8 output, including native wrapper/prefix, locale, CRLF and Unicode normalization form. The helper changes none of these.
- `rawSelectedBytesHash` hashes separately captured selected-source bytes, not a package or its returned wrapper. A folder has null raw source; its listing is a separate string digest.
- `boundedListingHash` hashes the provided native selected listing; it does not reconstruct a full registry/library or fetch blobs. When the gateway omits part of a prepared listing, that capture remains explicitly partial/unverified.
- `contentHash` is the domain-tagged content-surface-v1 digest over exact selected identity/operation/path/MIME and returned/listing hashes. It is not full-package authorization.
- `manifestDigest` separately binds raw/pre-gateway/finalizer-suffix hashes, all size/transform fields and the unverified capture labels. Same version/size or same sanitized display can still produce a different manifest when raw bytes change.

Complete, reader/gateway truncated, omitted and sanitized flags are explicit and mutually checked. Complete must be false when any loss/transform flag is true. Sanitization is checked against existing pgSafeText; unknown or incoherent flags yield no sealed buffer. A coherent observation still always declares `capture:unverified`, `transformationEvidence:unverified_capture`, `sourceContextPrivacy:unverified`, `fullPackage:false`, `authority:false`, `canExecute:false`. Hashing caller-supplied bytes proves their digest, not their provenance, semantic correctness or permission to disclose them. No ALLOW is produced.
