# ADR 0209 — Scoped agent-to-agent skill exchange
Status: FEATURE BRANCH; NOT DEPLOYED — 2026-11-22.

## User outcome
An agent learns from real sessions, observed mistakes and verified outcomes and produces an agent-origin reusable Skill. Agent A then nominates matching peers C/D/E, and AC safely assigns the Skill, records native agent communication, builds a Wiki knowledge page and keeps memory-source provenance. A fresh task on each peer actually loads the Skill, with verifiable version/run IDs and a failure/deny audit.

## Security boundaries
Only a source-verified, agent-origin, version-1, nonexecuting, public text Skill may be shared automatically. Require same organization and same human owner; the origin agent must own and already have the Skill, and named recipients must be active, callable and within audience, with no disabled grant override. A receiver must already have native skills:read capability; Skill assignment cannot grant it. If any nominee lacks that scope, sharing fails closed and owner-managed access stays unchanged. No cross-org fanout, scripts, new tool/repo/credential scopes, or changes to approval settings. Max three recipients per call. Require BOTH owner-managed agents_improve_skills and the new separate manager-controlled auto_share_learned_skills opt-in (default OFF via migration 0283). The auto_approve_learning lesson-instruction switch does not automatically enable Skill sharing; each policy is independent. Agents cannot enable either policy themselves. Only public text, first-version Skills created from verified repeated How-tos are eligible. Recheck source provenance, version, public channels and recipient status inside database transactions. Original memory note remains archived as evidence; a public Wiki page attributed to the actual agent may be written on success. Native peer messages use existing consultation and budget rules. Report partial delivery truthfully; never claim a notification or Wiki write without a receipt.

## Acceptance
Public A-to-CDE skill creation/promotion; exact linked source and human ownership verified; agentSkills assignment persists; C/D/E fresh native load_skill calls work; same skill body/version observed, Wiki page and memory note located, agent-to-agent communication IDs present. Negative tests: private, DM, missing/deleted sources, expired/changed grant, scripting, disabled prior grant, wrong tenant, wrong owner, duplicate retries, absent policy, denied audience. Production requires independent review, same-SHA full local CI, branch protection, deployed user-path and rollback.
