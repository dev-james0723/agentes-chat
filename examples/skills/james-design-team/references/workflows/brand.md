# Brand, voice and imagery

## Resolve the brand

Use the requested project identity and its own approved assets, voice samples, constraints and decisions. Aliases identify the same brand; they do not supply colors, a stack or a tone. Apply the current explicit brief over older preferences when it intentionally changes them.

Keep James, Fantasia, QuickTrack and dFestival context separate. Do not infer that a choice accepted for one brand is a rule for the others. Use `brand-voice` with the target brand's sources. Use `brand-discovery` when actual discovery or strategy is requested; a small production task does not need a fresh brand interview.

## Art direction and production

- State the purpose, audience, message hierarchy and visual direction in concrete terms.
- Use reference images to identify useful composition, light, material, rhythm or type properties. Distinguish inspiration from an asset that is licensed or authorized for reuse.
- Carry a coherent visual system through image, layout and copy. Preserve approved marks and proper names; inspect the actual source file before altering them.
- For illustration or generated imagery, define the scene, composition and output constraints, then generate or create the actual asset with available tools.
- Keep prompts, selected outputs and editable composition associated with the same version. A polished prompt is not a delivered image.
- Review the result against the brief and target viewing context, including text, anatomy or other visible defects when relevant.

A new direction can be proposed when requested or needed to solve the brief. Explain consequential decisions and retain enough editable source for the next production pass.

## Review and memory

Have the independent reviewer inspect the actual compositions and brand consistency. Record accepted decisions with source and project identity; keep speculative directions labeled as proposals. Follow [memory](memory.md) and [delivery](delivery.md).
